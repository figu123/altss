# altss

This is the "pipeline" of tools that I've been using throughout my project.

It requires using frtc https://github.com/alanlorenzetti/frtc/ first.

There's a lot of dependencies in the R script right now, 
I might want to reduce those later. Right now I just took easy options.
(Also there's a lot of tasks (eg. getting genomes) that would be easier 
to be made in bash rather than R)
